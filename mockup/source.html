Locked artwork. Everything else is yours to move.

The four official marks ship inside the theme as image assets and are referenced, never redrawn. Swap them for the traced vector exports when those land — the theme picks up whatever is uploaded in Settings.

Franchise expansion is already accounted for: the footer carries a store-locator slot and the value-prop row swaps to in-store pickup copy without a code change.

01Primary horizontal lockup on the desktop header and footer. Minimum 120px.
02Utility wordmark on the mobile header. Minimum 80px.
03Bird icon as the favicon and the marquee repeat mark. Minimum 16px.
04BQ monogram reserved for social, app icon and packaging seals — not the storefront.
05Clear space equals the width of the B stem, held by the trimmed asset files.
06The brand line sits near the logo, never locked to the artwork.
